\subsubsection{Decodificador de trama de IoT}

\textbf{Contexto:}

Estás trabajando en un sistema de domótica (IoT) que recibe mensajes de diferentes sensores. Para ser ultra-eficientes, todos los mensajes se empaquetan en exactamente 4 bytes (32 bits). El tipo de mensaje y sus datos están codificados dentro de esos 32 bits.

\begin{itemize}
    \item Los primeros 2 bits (los menos significativos) definen el tipo de mensaje.
    \item El resto de los bits (30) se interpretan de forma diferente según el tipo.
\end{itemize}

\textbf{Definiciones:}

\begin{enumerate}
    \item \textbf{Tipo de Mensaje (Enum):}
    \begin{itemize}
        \item \texttt{00} (binario) = \texttt{REPORTE\_TEMP} (Reporte de Temperatura)
        \item \texttt{01} (binario) = \texttt{REPORTE\_ESTADO} (Reporte de Estado de un Actuador)
        \item \texttt{10} (binario) = \texttt{ALERTA} (Mensaje de Alerta)
        \item \texttt{11} (binario) = \texttt{RESERVADO}
    \end{itemize}

    \item \textbf{Estructura de Datos (Campos de Bits):}
    \begin{itemize}
        \item \textbf{Si es \texttt{REPORTE\_TEMP}:}
        \begin{itemize}
            \item \texttt{tipo} (2 bits)
            \item \texttt{id\_sensor} (8 bits): Identificador del sensor (0-255).
            \item \texttt{temperatura} (10 bits): Un valor de 0 a 1023. Para obtener la T° real, se debe restar 100 y dividir por 10. (Ej. 500 = (500-100)/10 = 40.0°C).
            \item \texttt{humedad} (7 bits): Un valor de 0 a 127. Representa el \% (0-100).
            \item \texttt{\_relleno} (5 bits): No se usan.
        \end{itemize}

        \item \textbf{Si es \texttt{REPORTE\_ESTADO}:}
        \begin{itemize}
            \item \texttt{tipo} (2 bits)
            \item \texttt{id\_actuador} (8 bits): Identificador del actuador (0-255).
            \item \texttt{estado} (1 bit): 0=APAGADO, 1=ENCENDIDO.
            \item \texttt{potencia\_actual} (5 bits): Nivel de potencia (0-31).
            \item \texttt{\_relleno} (16 bits): No se usan.
        \end{itemize}

        \item \textbf{Si es \texttt{ALERTA}:}
        \begin{itemize}
            \item \texttt{tipo} (2 bits)
            \item \texttt{codigo\_error} (16 bits): Un código de error específico.
            \item \texttt{timestamp\_relativo} (14 bits): Segundos desde el último reinicio.
        \end{itemize}
    \end{itemize}
\end{enumerate}

\textbf{Tarea a Realizar:}

Escriba un programa en C que cumpla con lo siguiente:

\begin{enumerate}
    \item Defina la enumeración \texttt{TipoMensaje} (\texttt{REPORTE\_TEMP}, \texttt{REPORTE\_ESTADO}, \texttt{ALERTA}, \texttt{RESERVADO}).

    \item Defina tres (3) \texttt{struct} separadas usando campos de bits (bit-fields) que representen la estructura de \texttt{REPORTE\_TEMP}, \texttt{REPORTE\_ESTADO} y \texttt{ALERTA}.

    \item Defina una \texttt{union} llamada \texttt{TramaIoT} que contenga:
    \begin{itemize}
        \item Un \texttt{uint32\_t raw\_data;} (para acceder a los 32 bits crudos).
        \item Las tres (3) estructuras de campos de bits definidas en el paso 2.
        \item Una estructura genérica (ej. \texttt{struct \{ unsigned int tipo : 2; \}}) que solo sirva para leer los primeros 2 bits y determinar el tipo.
    \end{itemize}

    \item Implemente una función \texttt{void procesarTrama(TramaIoT trama)}.

    \item Dentro de \texttt{procesarTrama}, la función debe:
    \begin{itemize}
        \item Leer los 2 bits de tipo (usando la estructura genérica).
        \item Usar un \texttt{switch} basado en el \texttt{(TipoMensaje)} extraído.
        \item \textbf{Caso \texttt{REPORTE\_TEMP}:} Imprimir el ID del sensor, la temperatura (calculada en °C) y la humedad.
        \item \textbf{Caso \texttt{REPORTE\_ESTADO}:} Imprimir el ID del actuador, su estado (``ENCENDIDO'' o ``APAGADO'') y su nivel de potencia.
        \item \textbf{Caso \texttt{ALERTA}:} Imprimir el código de error y el timestamp.
    \end{itemize}

    \item En \texttt{main()}:
    \begin{itemize}
        \item Declare una variable \texttt{TramaIoT miTrama;}.
        \item Simule la recepción de un paquete asignando un valor hexadecimal a \texttt{miTrama.raw\_data}. Use \texttt{0x1A4C8401}.
        \item Llame a \texttt{procesarTrama(miTrama)}.
        \item Simule un segundo paquete. Use \texttt{0x00A2000A}.
        \item Llame a \texttt{procesarTrama(miTrama)}.
    \end{itemize}
\end{enumerate}
