\subsubsection{Ejercicio}
Realizar un programa que solicite al usuario ingresar un número entero positivo a través de la función declarada como \textbf{void ingresar\_positivo(int *)}. Esta función recibe como argumento un puntero a entero y debe validar que el número ingresado sea positivo. En caso de no serlo, solicitar nuevamente el ingreso del número. Finalmente, imprimir el número ingresado en la función principal. 

\subsubsection{Ejercicio}

Luego, llamar a la función \textbf{void suma\_y\_producto(float *a, float *b, float *suma, float *producto)} que recibe como argumentos punteros a los dos números ingresados y dos punteros a variables donde se almacenará la suma y el producto de ambos números respectivamente. Finalmente, imprimir los resultados en la función principal.

\subsubsection{Ejercicio}
Realizar un programa que solicite al usuario ingresar dos números enteros a través de la función \textbf{void ingresar\_en\_rango(int *, int min, int max)}. Esta función recibe como argumentos un puntero a entero y dos enteros que representan el rango válido de ingreso. La función debe validar que el número ingresado esté dentro del rango. En caso de no ser así, solicitar nuevamente el ingreso del número. Finalmente, imprimir el número ingresado en la función principal.

\subsubsection{Ejercicio}
Realizar un programa que solicite al usuario ingresar \textit{N} números enteros en un arreglo \texttt{vec}. \texttt{N} es una constante de preprocesador. La carga de los número se debe realizar a través de la función \textbf{void cargar\_arreglo(int *vec, int n)}. Esta función recibe como argumentos un puntero a entero y un entero que representa el tamaño del arreglo. Finalmente, imprimir los números ingresados en la función principal. Dentro de la función no se puede utilizar la constante \texttt{N}.

\subsubsection{Completar}
Responda cada uno de los siguientes:
\begin{itemize}[a)]
\item Una variable de tipo puntero contiene como su valor la \underspace otra variable.
\item Los tres valores que se pueden usar para inicializar un puntero son \underspace, \underspace y \underspace.
\item El único entero que se puede asignar a un puntero es el \underspace.
\end{itemize}

Indique si lo siguiente es verdadero o falso. En ambos casos, explique por qué.
\begin{itemize}[a)]
\item Un puntero que se declara nulo puede desreferenciarse.
\item Los punteros de diferentes tipos no pueden asignarse entre sí sin una operación de (cast).
\end{itemize}


Para cada uno de los siguientes items, escriba una declaración que realice la tarea indicada. Suponga que las variables de punto flotante \texttt{num1} y \texttt{num2} están inicializadas en 7.3.

\item Asigne la dirección del número \texttt{num1} al puntero \texttt{fPtr}.
\item Imprima el valor del objeto apuntado por \texttt{fPtr}.
\item Asigne el valor de la variable apuntada por \texttt{fPtr }a la variable \texttt{num2}.
\item Imprima el valor del \texttt{num2}.
\item Imprima la dirección del \texttt{num1}. Use el especificador de conversión \%p.
\item Imprima la dirección almacenada en \texttt{fPtr}. Use el especificador de conversión \%p. ¿El valor impreso es igual que la dirección del \texttt{num1}?
